# ISMS K9

A one-page team chat app built with React, TypeScript, Tailwind CSS, and shadcn/ui.

## Features

- Sidebar with seeded channels and direct messages
- Message thread pane for the selected conversation
- Composer that appends new messages locally
- Instant translation across 26 international languages (English, Spanish, French, German, Italian, Portuguese, Dutch, Russian, Polish, Turkish, Hindi, Bengali, Urdu, Arabic, Hebrew, Persian, Japanese, Korean, Chinese, Taiwanese, Vietnamese, Thai, Indonesian, Tagalog, Bisaya, Swahili)
